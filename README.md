# NORVAN

Sitio web de **NORVAN** — borcegos de hombre.  
Tagline: *Boots for the Journey*.

## Cómo verlo

Abrí `index.html` en el navegador, o serví la carpeta:

```bash
python3 -m http.server 8080
```

Luego visitá `http://localhost:8080`.

## Estructura

- `index.html` — Home (hero, colección, nosotros, calidad, contacto)
- `producto.html` — Ficha de producto + talles + carrito
- `css/styles.css` — Identidad visual
- `js/` — Catálogo, carrito y UI
- `assets/` — Logo e imágenes
